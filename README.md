# Intelligent Financial Advice Assistant

**Group DTP · AINL3001 Knowledge-Driven AI**

We plan to build a Python command-line assistant that helps students check whether they can reach a savings goal by a chosen deadline. It will use their income, expenses and current savings to calculate how much they can set aside each month. A rule-based system will use forward chaining to explain whether the goal is achievable and, where possible, suggest a revised timeline.
